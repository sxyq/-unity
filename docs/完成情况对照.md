## C. 逆向成果（可复用）

- **IL 摘要导出**：磁盘 DLL 加密，运行时导出 396 个类型的字符串/调用/字段 → `%TEMP%\gqy-il\`
- **指令通道**：`find / call / inst / stat / hide / show / buttons / methods`
- **窗口化能力**：注册表 `Fullscreen mode`（0/1/3）可切全屏/窗口
- **已知坑**：
  - Unity 抢 TOPMOST（已用跟随 tick 修复）
  - `HidoOpenPanelList()` 后通道失联（改用按名 hide）
  - DPI 150% 下两套坐标空间，逐面板不一致

## D. 结论

需求核心（大模型问答 + 场景识别 + 成绩/TTS）已落地并多数实测；
**唯一硬缺口**是对原实验 UI 的完整遍历——卡在平台取票链路的会话失效，属外部依赖。
