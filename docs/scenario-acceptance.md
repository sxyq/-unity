## 本轮关键更正（此前记录有误）

1. **39 项不是 39 个错项。** 原程序 `ScoreDatas` 对未作答项同样写
   `isRight=false / score=0 / time=0`。实测记录为：39 项、已作答 0、未作答 39、累计 0 分。
   状态层现在输出 `answeredItems / pendingItems / noAttempts`，面板与提示词都禁止把未作答当错项。
   > 判定口径：`isRight=true`、`score>0`、`time>0` 任一成立才算已作答。
   > 若原程序对某个已答但 0 分的项连用时也不写，则会被归为未作答；
   > 这种保守口径只会少报错项，不会凭空造出错项。
2. **成绩归属必须标注。** `current-running`（本次运行）/ `current-last-run`（上一次运行，已结束）/
   `history`（更早日志）。面板与提示词都按此口径，不再把旧记录说成"本次成绩"。
3. **报告场景不再锁考核。** 09/10 改为学习反馈模式；真正答题时（如术后并发症选择题）
   才触发 `examLock`，且不能被手动切场景解除。
4. **构建产物曾残留虚构患者。** `server-inject/public/hook.js` 还是旧版（王建国/3 床），
   已用当前 `case-data.js` 重新构建；现在全库只剩「李波 / 男 / 33 岁 / 2 床」。
5. **"实验已退出但仍显示运行中"已修。** 原逻辑把 5 分钟内写过的日志都算 live；
   现在本实验日志只有 60 秒内写过、或实验进程仍在，才算当前状态。
